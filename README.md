# GyMax
بک‌اند سامانه مدیریت باشگاه GyMax با Go و PostgreSQL. این نسخه شامل مدیریت کاربران و نقش‌ها، ثبت باشگاه، عضویت ورزشکار و زیرساخت تأیید شماره موبایل است.

GyMax is a gym-management platform built for coaches and athletes.

## ساختار پروژه

```text
GyMax/
├── backend/       API، منطق دامنه، repository و migrationهای PostgreSQL
├── frontend/      رابط کاربری Next.js، فارسی و انگلیسی
├── gymax.env      تنظیمات مرکزی IP، پورت‌ها، دیتابیس و کلیدهای توسعه
├── compose.yaml   پایگاه‌داده محلی
└── Makefile       فرمان‌های متداول توسعه
```

## اجرای محلی

1. پایگاه‌داده را با `docker compose up -d db` اجرا کنید.
2. IP سرور و پورت‌ها را در فایل مرکزی `gymax.env` تنظیم کنید. migrationها هنگام شروع بک‌اند خودکار اجرا می‌شوند.
3. بک‌اند را با `cd backend && go run main.go` اجرا کنید.
4. فرانت‌اند را با `cd frontend && npm install && npm run dev` اجرا کنید.

برای اجرای هم‌زمان دیتابیس، بک‌اند و فرانت‌اند می‌توانید در ریشه پروژه
`./run_project.sh` و برای توقف آن‌ها `./stop_project.sh` را اجرا کنید.

سرویس به‌صورت پیش‌فرض روی `http://127.0.0.1:8081` اجرا می‌شود. پاسخ‌های API فارسی هستند؛ برای دریافت پاسخ انگلیسی هدر `Accept-Language: en` ارسال کنید. زبان‌های پشتیبانی‌شده از مسیر `GET /v1/meta/locales` قابل دریافت‌اند.

رابط Next.js روی `http://127.0.0.1:3001/fa` اجرا می‌شود. مسیر انگلیسی `/en` است و ورود به `/` به فارسی هدایت می‌شود.

در محیط توسعه، کد OTP به‌جای ارسال SMS در log چاپ می‌شود. برای محیط production باید پیاده‌سازی `OTPNotifier` با درگاه پیامک جایگزین شود و `APP_ENV=production` باشد.

مدیر اولیه توسعه از مقادیر `GYMAX_ADMIN_*` در فایل مرکزی `gymax.env` ساخته می‌شود. این مقادیر پیش از استقرار واقعی باید تغییر کنند.
