# ClubMax
بک‌اند سامانه مدیریت باشگاه ClubMax با Go و PostgreSQL. این نسخه شامل مدیریت کاربران و نقش‌ها، ثبت باشگاه، عضویت ورزشکار و زیرساخت تأیید شماره موبایل است.

ClubMax is a gym-management platform built for coaches and athletes.

## ساختار پروژه

```text
ClubMax/
├── backend/       API، مدل‌ها، منطق دامنه و repositoryهای PostgreSQL
├── frontend/      رابط کاربری Next.js، فارسی و انگلیسی
├── clubmax.env.example  الگوی تنظیمات مرکزی IP، پورت‌ها و کلیدها
├── compose.yaml   پایگاه‌داده محلی
└── Makefile       فرمان‌های متداول توسعه
```

## اجرای محلی

1. پایگاه‌داده را با `docker compose up -d db` اجرا کنید.
2. در نصب جدید، `clubmax.env.example` را با نام `clubmax.env` کپی و IP، پورت‌ها و رمزها را در همان فایل مرکزی تنظیم کنید. اسکیمای دیتابیس هنگام شروع بک‌اند از مدل‌ها ساخته می‌شود.
3. بک‌اند را با `cd backend && go run main.go` اجرا کنید.
4. فرانت‌اند را با `cd frontend && npm install && npm run dev` اجرا کنید.

برای اجرای هم‌زمان دیتابیس، بک‌اند و فرانت‌اند می‌توانید در ریشه پروژه
`./run_project.sh` و برای توقف آن‌ها `./stop_project.sh` را اجرا کنید. در اجرای اول، وابستگی‌های فرانت‌اند در صورت نبودن به‌صورت خودکار نصب می‌شوند.

سرویس به‌صورت پیش‌فرض روی `http://127.0.0.1:8081` اجرا می‌شود. پاسخ‌های API فارسی هستند؛ برای دریافت پاسخ انگلیسی هدر `Accept-Language: en` ارسال کنید. زبان‌های پشتیبانی‌شده از مسیر `GET /v1/meta/locales` قابل دریافت‌اند.

رابط Next.js روی `http://127.0.0.1:3001/fa` اجرا می‌شود. مسیر انگلیسی `/en` است و ورود به `/` به فارسی هدایت می‌شود.

در محیط توسعه، کد OTP به‌جای ارسال SMS در log چاپ می‌شود. برای محیط production باید پیاده‌سازی `OTPNotifier` با درگاه پیامک جایگزین شود و `APP_ENV=production` باشد.

مدیر اولیه توسعه از مقادیر `CLUBMAX_ADMIN_*` در فایل مرکزی `clubmax.env` ساخته می‌شود. این مقادیر پیش از استقرار واقعی باید تغییر کنند.
