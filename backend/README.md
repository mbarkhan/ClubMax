# ClubMax Backend

سرویس HTTP نوشته‌شده با Go و PostgreSQL است. ساختار داخلی آن به‌ترتیب شامل `domain`، `repository`، `service` و `handler` است و نقطه ورود برنامه در `main.go` قرار دارد.

برای اجرای محلی کافی است دیتابیس ClubMax را با `../run_project.sh` راه‌اندازی کنید؛ پس از آن `go run main.go` بدون هیچ پارامتر یا متغیر محیطی اجرا می‌شود. برنامه تنظیمات را مستقیماً از `../clubmax.env` می‌خواند و اسکیمای نهایی را هنگام شروع از مدل‌ها ایجاد می‌کند. پورت پیش‌فرض API برابر `8081` است.
